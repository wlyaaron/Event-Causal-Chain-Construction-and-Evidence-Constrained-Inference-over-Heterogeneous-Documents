# 赛题 4：候选链如何影响 answer，以及四类拒答提示词实验

> 2026-10-10 的探索性配对实验。基线代码、候选池、V4 提示词与当时报告已冻结在 Git 标签 [`task4-candidate-answer-v2-frozen-20261010`](https://github.com/wlyaaron/Event-Causal-Chain-Construction-and-Evidence-Constrained-Inference-over-Heterogeneous-Documents/tree/task4-candidate-answer-v2-frozen-20261010)。本页的模型是 DeepSeek API `deepseek-flash`，沿用服务商默认思考设置；API 输入均为同包完整可见材料与当前问题，**没有发送 gold**。所有分数只用训练集原始完整 gold 在本地事后计算，不是官方测试分。

## 1. 先问清楚：候选链本身是否让答案变差？

冻结的同一批 A 视图 50 题中，纯 V4、原始候选版、后来的答案对齐 V2，以及本轮“仅删除 V2 中一段 answer 对齐指令”的版本如下。最后两列使用相同候选、V4 system prompt、单链要求、模型和 32768 输出上限；差异只有那段额外的 answer 指令。

| 同一 50 题 | 纯 V4 | 原始候选版 | 候选＋答案对齐 V2 | 候选＋单链、无额外 answer 段 |
|---|---:|---:|---:|---:|
| 有效输出 | 50/50 | 44/50 | 50/50 | **50/50** |
| 答案字符 F1 | 0.4070 | 0.3586 | 0.3781 | **0.4230** |
| 答案语义余弦 | **0.7952** | 0.7023 | 0.7777 | 0.7841 |
| 证据节点 F1 | 0.8522 | 0.7614 | 0.9258 | **0.9278** |
| 有向边 F1 | 0.7121 | 0.6485 | **0.8125** | **0.8125** |
| 完整链命中 | 26/50 | 28/50 | **40/50** | **40/50** |
| 有效答案平均字符数 | 169.88 | 161.68 | 175.96 | **131.46** |
| 输出 token，含思考 | 96,009 | 132,343 | 125,502 | 125,519 |

**如何读原始候选版的低分：**六道题的输出无效，在固定 50 题分母中记零。仅在两边都有有效输出的同一 44 题上，纯 V4 与原始候选版字符 F1 为 **0.4060／0.4075**，语义为 **0.7948／0.7980**。这是事后按有效性筛出的子集，不能代替 50 题成绩；但它否定了“候选一加入，所有有效答案就普遍变差”的简单解释。原始候选把列表误抄成二维链、或在 8192 token 上限截断，是首先要解决的格式风险。

V2 与本轮单链版的差异更直接：**50 题均有效，完整链都中 40 题，其中 44 题提交的链完全相同**；移除额外 answer 段后，字符 F1 **36 题升、14 题降**，均值 **0.3781→0.4230**，语义 **0.7777→0.7841**。这说明 V2 对“answer 尽量只引用链内材料”的强约束确实改变了答案写法，且在这批题上产生了净损失。纯 V4 的语义 **0.7952** 仍更高，不能说答案问题已经彻底解决；单链版对纯 V4 的逐题语义为 22 题升、28 题降。50 题曾用于前一版规则设计，本轮依旧只是开发诊断。

### 一道链完全相同、answer 反而不同的题

`natural_disaster_072_Q04` 的原始 gold 要求写明“台风生成增强 → 首次登陆 → 部署防御 → 防灾减灾能力提升”。V2 的链正确，但 answer 主要复述 `D001→D002→D003→D010` 与边型；去掉额外 answer 段后，链仍相同，answer 恢复了台风、登陆、部门部署和结果的事件含义。该题的字符 F1 相对 V2 提高约 **0.26**、语义提高约 **0.13**。[逐题原答和指标](../experiments/results/task4_answer_refusal_ablation_20261010.json)

### 仍未解决的一道题

`economy_trade_133_Q06` 的 gold 是 `D001→D002`，即政策发布后专家解读；单链版选择了图中另一条直接边 `D001→D003`（工作部署）。它虽不再枚举整包后果，answer 语义却比纯 V4 低约 **0.14**。这属于**平行候选选错导致 answer 主结论也换了**，不是靠缩短或固定 answer 句式能补救的。因而后续需要把“候选选链”和“按所选链表述”作为两个误差来源分别验收。

## 2. 拒答：全量 gold 有四种写法，直接改提示词后怎样？

全训练集 937 道 `question_type=unanswerable` 中，原始 gold 有 **844 道严格“无法确定”＋空链**、**38 道纠正错误前提**、**43 道排除干扰材料**、**12 道解释性证据不足**。后三类均有非空 gold 证据锚点。V5 在 V4 上明确列出四类及条件，不凭题型直接分类。首轮 90 题出现“能否精确量化”被当成“请解释为何无法量化”，于是 V6 增加**先看主要交付对象**的优先级规则。全训练集含“能否精确量化”的 618 题中，616 道 gold 严格拒答、2 道有证据的限定解释；因此 V6 仍保留原文核查出口，没有用程序按关键词强制改答。[审计数据](../experiments/results/task4_refusal_quantity_audit_20261010.json)

| 旧 90 题，同题配对 | V4 | 四分支 V5 | 优先级修订 V6 |
|---|---:|---:|---:|
| 有效输出 | 78/90 | 82/90 | 80/90 |
| 严格 gold 命中 | 17/24 | **14/24** | **19/24** |
| 非严格 gold 误拒 | 1/66 | **2/66** | 1/66 |
| 完整链命中 | 44/90 | 40/90 | 45/90 |
| 答案字符 F1 | 0.4690 | 0.4588 | 0.5086 |
| 答案语义余弦 | 0.7160 | 0.7263 | 0.7397 |

V5 是明确负结果。V6 在这批**已被用于定位和修改规则**的 90 题上优于 V4，但不能把它当成独立验证。V6 仍有 10 题无效，其中有达到 8192 输出 token 上限的题；严格拒答也从 V4 正确转错 1 题，不能只看净增数。

| 另一组 30 题，同题配对 | V4 | 固定后的 V6 |
|---|---:|---:|
| 有效输出 | 27/30 | 27/30 |
| 严格 gold 命中 | 9/12 | 10/12 |
| 非严格 gold 误拒 | **0/18** | **1/18** |
| 完整链命中 | 15/30 | 15/30 |
| 答案字符 F1 | 0.5165 | 0.5589 |
| 答案语义余弦 | 0.7534 | 0.7615 |

这 30 题的 V6 在查看其结果前已固定，但它仍是既有的小型压力样本，并非自然频率的独立总体估计。`natural_disaster_162_Q05` 的 gold 严格拒答，V4 写成“不能精确量化”加解释，V6 改为精确“无法确定”；`economy_trade_074_Q09` 则相反，gold 要求解释未经证实的方案为何信息不足，V6 错误地严格拒答。`energy_environment_04_Q02` 的 gold 严格拒答，V4 正确，V6 却转成纠正错误前提的长解释。四分支规则有收益，也仍会错分交付对象，**不能仅凭严格拒答 9→10 宣称拒答性能稳定提高**。[逐题原答、原始 gold 与分项指标](../experiments/results/task4_answer_refusal_ablation_20261010.json)

## 3. 当前决策

1. **候选链与 answer：**本轮优先保留“候选＋单链、无额外 answer 段”作为下一次验证的候选版本；它在开发 50 题保留 40 条完整链，字符 F1 回升。但语义仍低于纯 V4，平行直接后果选错仍会把答案带偏。不要用固定答法掩盖错误分支。
2. **拒答：**V5 不采用。V6 保留为研究分支；旧 90 与另一 30 的结果方向总体较好，但后一组有 1 道解释性题被误拒。下一步须同时压低这类误拒和输出无效，才考虑替换 V4。
3. **实验边界：**三个题集已经参与不同程度的设计和诊断；没有从无 gold 的 760 道测试题判逐题对错，也没有用其调参。继续评估时需在尚未参与改写的材料包上冻结提示词、候选代码和分母，再同时报告 answer、链、严格拒答与误拒。DeepSeek 输出仍只作为研究对照。

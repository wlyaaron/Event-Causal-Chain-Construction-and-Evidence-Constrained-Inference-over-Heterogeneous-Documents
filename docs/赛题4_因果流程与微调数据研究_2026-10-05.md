## 证据来源与假设

当前缺口的发现首先来自赛题结构、现有代码和既有配对实验；论文用于提出可证伪的改法，不等于论文已证明本题提分。此前 BM25/学习式排序提高候选覆盖，最终答案和完整链没有稳定增益；A 档无条件关系说明仅在 4 题上改善答案代理指标，边 F1 下降；锁链改答案未获净收益。详见[前期研究记录](赛题4_模型无关优化研究_2026-10-04.md)。

- H1（A 档）：题目条件化的**局部**路径候选，比根到叶路径候选更容易覆盖一条完整金标链，并可能提高最终节点/边 F1 与链完全匹配。灵感是 [RoG](https://arxiv.org/abs/2310.01061) 的规划—图内检索—回答，以及 [Beam Retrieval](https://aclanthology.org/2024.naacl-long.96/) 保留多个部分假设。必须分别测候选覆盖和最终输出。
- H2（A 档）：保留给定边的关系类型、等级和文档片段，再提示逐边核验，可能比统一改写为“导致/推动”更准确。[TAG-EQA](https://aclanthology.org/2025.starsem-1.24/)只证明其他事件问答数据上图文结合有潜力；[iLIF](https://aclanthology.org/2024.acl-long.210/)和 [Suggest–Verify–Revise](https://aclanthology.org/2026.acl-long.871/)提示要把因果方向和结构一致性作为独立判断。边表缺步的金标需分层评估，不能把图约束当作真值。
- H3（B/C 档，后续）：先测事件对因果存在性和方向，再测组链；先测材料充分性和冲突，再测拒答。[Sufficient Context](https://research.google/pubs/sufficient-context-a-new-lens-on-retrieval-augmented-generation-systems-2/)为充分性判定提供框架。当前不把同一套 A 档图提示偷用于 B/C。

本轮流程实验预先比较**同一模型别名、同一留出题**的原始输入与 H1+H2 组合。答案字符 F1、语义相似度、关键事实覆盖、证据节点/边 F1、链完全匹配、拒答、请求量和 token 成本分别报告。本地指标只是代理。若候选覆盖提高而最终指标未提高，记录为负结果。

## 微调数据决策

[ACL 2024 证据问答研究](https://aclanthology.org/2024.acl-long.105/)发现数据支持质量比盲目增加数量重要；[LearnDA](https://aclanthology.org/2021.acl-long.276/)说明事件因果增强须保持因果标签。当前只使用赛事训练集。

1. 保留原始文件。缺失事件 ID 或当前输入视图不兼容的链隔离；边表未列出的步骤、解释性 `unanswerable`、缺 `required_facts`、非标准置信度和多条金标链做软标记与分层评估，不机械删除。
2. 按材料包和完全相同文档分组划分。`sample_id` 不能跨训练/测试当作全局键；测试集无金标，不能调参。
3. A/B/C 训练输入与推理可见信息一致。每题所有完整且当前视图 ID 合法的金标备选链作为元数据保存；监督输出一次只用**其中一条原样链**。金标链不能合并；某条边不在边表中不自动生成负例。
4. 不给 `confidence` 凭类别伪造数值标签。未来需用离线模型在包隔离验证集上校准。
5. 外部中文事件数据（例如 [DEIE](https://aclanthology.org/2024.lrec-main.410/) 或 [DocEE-zh](https://aclanthology.org/2024.findings-emnlp.35/)）只列为候选；许可、任务映射、与赛题数据重合及赛事披露要求未完成核验前不加入。
6. 暂不生成合成问答或伪标签。先实现可复现的多参考训练样本选择；文档顺序扰动、干扰项和反事实负例需在首轮 SFT 后按实际错误和标签稳定性另做消融。

本文件记录实施前决策。实验结果和失败分析会在本文件追加，不能把检索指标提升写成最终提分。

## 实施与阶段性结果

`task4_workflow.py` 新增问题条件化的局部有向路径候选和边类型／等级／原文片段索引；旧提示仍保留，便于对照。按 2026-10-05 既有材料包划分，从未参与前期 40 包探索、100 题及上一组路径答案实验的包中冻结首组 `experiments/causal_path_holdout_20261005.json`（12 题，四大题型各 3）。第二组 `experiments/causal_path_holdout_second_20261005.json`（11 题，三种可回答题型各 3，拒答 2）与首组无包和题号重叠；不足 3 道新的合格拒答题，故样本数较少。两组都排除与拟合集完全相同的问题＋答案。选择清单没有金标答案，推理函数不读取 gold。研究 API 仍为同一 `deepseek-flash` 别名，输出全在忽略的 `outputs/`。

首组前 5 条候选包含任意完整金标链的题数从旧根到叶提示 **3/12** 到新局部路径 **6/12**；第二组从 **1/11** 到 **6/11**。这只是候选 oracle 覆盖，不是最终分数。

首组同题配对的本地代理指标（原始输入→局部因果路径索引）：答案字符 F1 **.4704→.5167**、BGE 答案余弦 **.8168→.8336**、关键事实覆盖代理 **.2500→.2917**、节点 F1 **.7724→.8801**、边 F1 **.6216→.7929**、链完全匹配 **5/12→8/12**、拒答判断 **12/12→12/12**。关键事实覆盖使用未校准的每项 BGE 余弦 ≥.70，不是官方算法。三道拒答题两侧都正确，首组提升主要来自其余九题。前瞻题 `economy_trade_193_Q07` 是负例，边 F1 下降 .4；另一道前瞻题 `natural_disaster_091_Q03` 仍未得到完整长链。首组每臂基础请求 12 次，增强臂另有 1 次截断重试；报告用量原始 107,862 tokens、增强 137,890 tokens，实际费用受缓存与重试影响。

独立第二组保持同一算法，最终结果弱于首组：答案字符 F1 **.4678→.4566**、语义余弦 **.8064→.7919**、关键事实覆盖代理 **.3939→.5152**、节点 F1 **.7216→.7758**、边 F1 **.5591→.6439**、完整链 **5/11→5/11**、拒答判断 **11/11→11/11**。两组合计 23 题：答案字符 F1 **.4692→.4880**、语义 **.8118→.8137**、关键事实代理 **.3188→.3986**、节点 **.7481→.8302**、边 **.5917→.7217**、完整链 **10/23→13/23**、拒答判断 **23/23→23/23**。平均模型自报非拒答 confidence **.8606→.8522**，尚无校准证据，不能换算官方置信度分。合计每臂成功基础请求 23 次，各有 2 次截断重试；原始／增强报告用量 **252,743/287,899 tokens**，按同一价格页口径估算两臂分别约 **$0.071–$0.142 / $0.083–$0.165**，截断调用用量不完整，实际费用可能更高。

**失败分析与结论。** 第二组 `economy_trade_059_Q02` 明问“追溯多跳因果链”，增强路径提示却偏短，模型把原本完全匹配的长链缩成 `D004→D006→D008→D009`，丢失必要上游，答案字符 F1 下降 .132、边 F1 下降 .25。`economy_trade_125_Q07` 的前瞻题把金标 `D001→D003` 延长成 `D001→D003→D007`，完整链仍不匹配，答案也下降。首组 `natural_disaster_091_Q03` 的十节点金标长链亦未完整恢复。新方法在两组都提高**候选覆盖、节点和边 F1**；但答案字符／语义与链 exact 在独立第二组没有稳定增益，不能宣称稳定最终提分，更不能据训练代理推断线上 59.55 会提高。下一假设是区分题目是否明确要求“完整上游过程”与“预测后续”，对路径终点和长度做更严格条件化，再在新的包上验证；当前代码保留为研究实验入口，不替换已保存的基线生成流程。

微调数据脚本保留每题在该输入视图中 ID 合法的所有完整金标链；选择监督目标时优先选给定图支持的一条，但**不因缺边表步骤而删掉整题**。新版输出 `outputs/finetune_2026-10-05_v2/` 的 A 拟合／验证／保留分别为 **5767/437/476**，旧版为 **5266/390/433**；A 档隔离数从 1107 降至 516。B/C 数量不变，包划分仍为 801/101/98。A 拟合集有 2184 条样本含多条兼容金标链，501 条没有任何逐边可见图支持的完整金标链，可作为单独消融层，不冒充高置信因果真值。`experiments/sample_multireference_epoch.py` 用种子、轮次、材料包与题号确定性选取一条**原样**金标链，已生成 5767 条 epoch 1 样本；重复运行 SHA-256 完全相同，所有选中链均属于各题原有备选集合。未加入外部语料、合成问答或置信度伪标签。

**阶段判断。** 新流程在训练包隔离小样本上两次提高候选覆盖和证据节点／边代理指标，在 760 题 A 档上也显著提高与给定边表的一致性；它尚未证明关键事实覆盖、完整链或平台总分稳定提高。长链被截短和解释性无答案题转为完全拒答是具体风险。下一次流程改法须先在有 gold 的新材料包上比较“完整过程”与“直接关系”的链长度、证据节点／边、关键事实和答案，再考虑替换默认推理。微调数据 v3 足以作为首轮**诊断性 SFT 数据候选**；在选定离线开源模型后仍需按其 tokenizer 审计截断与证据位置，并用验证集处理正式格式中的数值置信度。当前不加外部语料、伪标签或未经核验的数据增强。

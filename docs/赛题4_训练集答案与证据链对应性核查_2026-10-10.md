# 赛题 4：训练集 answer 与证据链是否严格对应

## 结论

**不能在所有题上强制 answer 只提及最终 `evidence_chain` 的事件。**全量 1,000 包、7,196 题中，6,339 题给出非空 gold 链；5,305 题的 gold answer 明写至少一个合法事件 ID。在这 5,305 题里，3,736 题的全部明写 ID 可同时包含在某一条完整 gold 备选链中，另有 **1,569 题不能**。这里逐条检验完整备选链，没有将不同备选链拼接。数据见 [审计 JSON](../experiments/research_audit_20261010/answer_chain_alignment.json)。

| 推理类型 | 有链且 answer 写合法事件 ID | ID 超出每一条完整备选链 |
|---|---:|---:|
| 多跳因果 | 1,693 | 17 |
| 单跳因果 | 891 | 19 |
| 时间因果 | 881 | 25 |
| 反事实 | 884 | 812 |
| 有依据的预测 | 885 | 654 |
| 干扰识别 | 38 | 26 |
| 冲突来源 | 23 | 16 |

这是一项**显式事件 ID 的必要条件检查**，不是完整语义事实核查：1,891 道答案没有明写合法事件 ID，且即便 ID 全在链上，也可能叙述链外事实。因此，“所有 answer 的每一事实均不越过链”无法由此证明。相反，已经找到明确反例，所以全题型硬性禁止链外信息不成立。

## 直接反例

- `public_safety_022_Q05`：gold 链仅 `D001→D002`，answer 先回答 D002，又补充 D003、D004、D005、D006 这些其他直接后果。这些 ID 不在任何备选链内。类似模板在多包出现。
- `public_safety_007_Q07`：gold 备选为单节点 `D014`、`D004`、`D012`，answer 同时比较早期说法、调查报告及官方通报，无法把三个 ID 装进任何一条备选链。
- `public_safety_033_Q02`：gold 链仅单节点 `D006` 或 `D005`，answer 为说明“时间先后不等于因果”还提及 D004 作为另一直接原因。
- 反事实题常在 answer 中列出受移除节点影响的多条边，预测题常描述多个可能后续，故不能用一条链限制整个解释段落。

## 与这 50 题的关系

本次冻结的 50 道 A 类回溯题，按显式 ID 检查，**50/50** 的 gold answer 均可对应某一条完整 gold 链。这支持为当前目标题型加入“围绕最终选出的链组织核心答案”的提示，但不意味着 gold 的每个未标 ID 的事实都可自动证明出自链内原文，也不保证在其他题型适用。特别是含对照、否定、干扰识别、冲突来源的题，必须允许必要的链外对照事实，并说明它们是对照，不要拼入因果链。

因此下一版提示词采用条件约束：**可回答的因果过程或直接后果题，先选一条路线，再让 answer 的主结论和关键事实由该路线支撑；避免额外列举平行后果。**判断、反事实、冲突与干扰题可简短引用必要链外对照；仍只提交一条一维 `evidence_chain`。这不是用 gold 为每题指定哪条路线，模型仍必须依据原文和关系独立选择。

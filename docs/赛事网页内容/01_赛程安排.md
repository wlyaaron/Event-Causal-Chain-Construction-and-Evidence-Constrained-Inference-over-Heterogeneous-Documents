# 赛程安排

来源：https://www.heywhale.com/org/cunsl/competition/area/6aba35f66e5beff2fca5b1e8/content/0

抓取日期：2026-10-02

---

该赛题采用初赛、复赛、决赛的“三级赛制”，具体赛程安排如下：

**2026/09/30-10/14，初赛阶段**

2026/09/30，发布大赛赛题，选手可登录大赛官网报名；

2026/10/01，发布初赛赛题数据，选手可登录PC端大赛官网赛题详情页下载数据集；

2026/10/04，开启初赛作品提交及线上评测。选手可在线提交结果文件至竞赛平台，每日每队最多可提交3次，测评系统将自动评测得分并同步更新至排行榜。排行榜上将记录选手的最高成绩，相关团队必须自行保存最高成绩作品的源代码以备审核；

2026/10/14，初赛结束并进行成绩公示，遴选10支团队入围复赛。

**2026/10/15-10/17，复赛阶段**

2026/10/15-10/17，开展复赛。选手可登录PC端大赛官网赛题详情页下载数据集，同步开启复赛线上评测。选手可在线提交结果文件至竞赛平台，每日每队最多可提交3次，测评系统将自动评测得分并同步更新至排行榜。排行榜上将记录选手的最高成绩，相关团队必须自行保存最高成绩作品的源代码以备审核；

2026/10/17，复赛阶段结束，遴选5支团队入围决赛。

**2026/10/23，决赛阶段（深圳）**

2026/10/23，组织线下专家评审，入围决赛团队现场答辩，公布优胜队伍，并组织颁奖典礼。

**决赛后，反作弊审核及成绩复现阶段**

决赛结束后，组委会将组织开展反作弊审核及作品成绩复现工作。

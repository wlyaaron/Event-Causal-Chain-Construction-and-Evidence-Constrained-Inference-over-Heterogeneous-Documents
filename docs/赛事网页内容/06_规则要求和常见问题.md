# 规则要求和常见问题

## 一、通用规则
**参赛对象：** 面向全国各工业部门、科研院所、高校、民营企业。

**报名要求：** 参赛队须以单位名义报名，同一单位可有多支不同的参赛队。其中，“公开赛道”中参赛选手可报名参加多个赛题，但在同一赛题中仅能报名参加一支团队。“邀请赛道”中参赛选手报名参加《谈判对手长文本观点挖掘与预测(邀请赛)》和《跨大视角下的海面目标检测与识别(邀请赛)》赛题，则该选手不可重复报名参加“公开赛道”对应的《谈判对手长文本观点挖掘与预测》《跨大视角下的海面目标检测与识别》赛题。报名时所有参赛队成员需提供所在单位信息、个人基本信息，并进行实名认证;参赛选手应当保证各项信息的真实性。学生参赛者报名须指定至少一名所在单位任职的具有中级职称以上相关领域科研工作者作为团队指导教师。大赛组委会承诺其中涉及个人隐私的内容予以保密。

**组队要求：** 所有报名参加同一赛题的参赛者，可在PC端进行组队操作。所有参赛选手应在截止日期前自行完成组队，每队1-5人（含指导教师），不可重复组队。并以团队身份提交各阶段的作品材料，一旦进入团队，不可退出队伍。多个单位的参赛者联合组队时，队长所在单位为该参赛队的第一单位。

**队长责任制:** 各团队队长作为团队的负责人，需自行进行团队内部分工和协调，并承担与大赛组委会对接沟通(包括但不限于晋级入围、团队信息收集、作品审核、线下活动等)的责任。

**回避原则:** 参与大赛出题的人员禁止参与所出具的赛题(可参与其他赛题)，禁止委托他人参赛或违规指导参赛团队。
## 二、专项规则

1. **是否能使用外部数据**：可以使用公开的外部数据和预训练模型，但需要在提交说明中注明来源和使用方式；
2. **是否可以对训练数据打伪标签**：允许使用半监督和自训练方法，但需要在技术报告中说明具体方法；
3. **模型使用限制**：不允许使用闭源API模型（如GPT系列、文心一言、Claude等），允许离线使用开源模型（如Llama、Qwen、ChatGLM等）；
4. **复现资料要求**：需要提交完整的源代码、模型权重、运行环境说明和复现步骤，确保算法可以复现；
5. **提交限制**：每个团队每天最多提交3次，排行榜记录最高成绩；
6. **公平竞争**：禁止手动打标、禁止抄袭、禁止使用测试集信息进行训练，违者取消参赛资格。

## 三、常见问题

* **Q1：任务A、B、C是否需要分别提交结果？**
  **A**：选手只需要提交单个JSON文件，最终会按照60%/30%/10%加权计算总分。
* **Q2：无答案题如何评分？**
  **A**：无答案题的标准答案为“无法确定”，evidence_chain为空列表，confidence为null。如果系统正确输出“无法确定”，则获得满分；如果系统强行给出答案，则答案正确性和置信度得分为0。
* **Q3：证据链的顺序重要吗？**
  **A**：重要。证据链需要按照从原因到结果的顺序排列，顺序错误会影响因果结构得分。
* **Q4：如果有多个可能的答案怎么办？**
  **A**：可以选择最合理的一个答案提交，评分时会与所有可接受的标准答案进行比较，取最高分。
* **Q5：训练集和测试集的领域分布一致吗？**
  **A**：训练集主要覆盖4个领域（公共安全、政治外交、经济贸易、自然灾害），测试集覆盖全部11个领域，用于评估模型的跨领域泛化能力。
